# 参考驱动的三维建模与质量闭环

目标：交付与参考形体相符、真实可编辑、可检查和可恢复的模型，而不是只在一个角度好看的图像。不要用部件齐全、面数很多或未经定义的“相似度 90%”代替质量证据。

执行前确认有可用的 Blender 操作途径、参考图读取能力和可写入位置。本技能提供流程与清单工具，不提供建模执行连接器；缺少能力时说明具体缺项，不声称已完成未执行的建模或检查。

## 开始前确定范围

- 读取全部参考图片和用户约束，不只挑两个方便的视角。列出各图的可见区域、遮挡、透视、关键轮廓、负空间、连接方式及不确定部分；区分“观察到”“尺寸指定”“推断”。
- 确定对象类型、用途、交付格式、是否需绑定或动画、尺寸单位和预算。尺寸缺失时可做比例重建，明确真实尺度未知，不编造精确尺寸。
- 将用户指定的外包围盒、局部尺寸、插槽/安装点坐标及公差列为独立约束，记录坐标系、原点和单位。约束冲突先指出，不以完成后的全局缩放掩盖错误。
- 在原文件副本或新版本工作；未经要求不覆盖已批准版本。只使用任务授权的输入与保存位置；本技能不授予发布、安装或第三方上传权限。

## 建模路径

1. 先做主轮廓和比例，再做标志性形体，最后细节。按参考视角设置可复现相机；透视参考先匹配投影，不把透视缩短直接当作真实尺寸。
2. 对识别度高的重复部件，先做一个有正确截面、曲率、厚度和连接的样件，并与近景参考比较，再复制、阵列或实例化。不要批量复制错误模板。
3. 硬表面：用真实实体/壳体、合理分件、倒角和接缝建形。需要厚度的板件必须有内外表面及边缘连接；双面材质不等于厚度。管线、铰链、支架须在合理安装点连接，不能悬空穿插。细节优先服务轮廓、负空间与结构关系。
4. 有机对象：改用整体体块、解剖/生长结构、雕刻、重拓扑和必要的置换/法线烘焙；动画资产检查变形拓扑。不把硬表面板件拼装或“一律封闭加厚”强加到毛发、叶片或有意开放的表面。
5. 保持 Blender 源工程可编辑：有意义的对象/集合命名，保留必要的修改器、实例源、材质与重建参数。交付需要时在导出副本应用修改器，而非破坏唯一源文件。
6. 纹理不能遮掩错误几何。投影贴图逐面检查，侧面/背面用合适的展开或重新投影，避免正面图被拉长包到侧面。不要让图像平面冒充用户要求的三维实体。

## 双重质量关卡

按 [references/quality-gates.md](references/quality-gates.md) 检查，技术通过和视觉通过分别记录。

- 每轮都对照关键轮廓、主要比例、负空间、关键零件位置和结构连接；检查全部已提供参考视角。用相同投影/构图的对照图或掩膜叠加定位差异，不能用不同角度的漂亮渲染替代比较。
- 尺寸和安装点在最终求值几何及统一坐标系下复核。检查厚度、背面、法线、接触/穿插、UV 与依赖文件。标明哪些检查没有做。
- 修复最影响外观的差异后再加微细节。若仍有显著误差，说明具体部位，不以面数或技术检查合格宣告高还原。
- 导出 GLB 后，在独立干净场景回读该文件，检查实际尺寸、朝向、材质、纹理、实例/修改器结果及必要的动画。源场景正确不保证导出正确。

## 先可恢复保存，再发预览

在向用户发送每个阶段预览之前，先完成该版本的可恢复检查点，遵循 [references/checkpoint-delivery.md](references/checkpoint-delivery.md)。预览必须对应已保存的相同版本。

- 检查点包含当前源工程、依赖纹理、存在时的重建代码/配置、当前导出、QA 证据和哈希清单。手工建模无需虚构全自动重建脚本，但必须有可打开的源工程及必要说明。
- 临时工作目录不是持久化交付。将检查点保存至当前任务已获授权且可验证持久保存的位置；验证写入和读取，记录真实保存凭证。不要要求某个固定账户或连接器。
- 用户指定保留的本地项目目录可作为保存位置；记录路径、重开源工程和清单验证结果，并说明仅本地保存。不要默认要求云端上传，也不把本地保存说成异地备份或永久保存保证。
- 若没有可用的持久保存渠道，保留本地成果，直接说明阻塞并请求最小必要的保存方式。不要声称已备份，不先发可能无法恢复的模型预览。
- 随交付简述：已完成内容、视觉偏差、技术检查范围、未验证项、源文件与导出位置。完整的运动干涉、工程强度和制造可行性不是静态视觉建模检查能保证的。

## 附带工具

使用 `python scripts/checkpoint_manifest.py create <检查点目录>` 生成清单，使用 `python scripts/checkpoint_manifest.py verify <检查点目录>` 复核文件大小与 SHA-256；工具仅需 Python 标准库。用法和局限见检查点参考。哈希一致只证明文件内容一致，不证明模型正确、保存持久或已获授权。
