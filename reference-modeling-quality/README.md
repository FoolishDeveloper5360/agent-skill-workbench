# 参考驱动三维建模

让 AI Agent 根据参考图、多视图或尺寸要求制作和修改可编辑的 Blender 模型，并检查形体、结构、导出文件和工程保存。

适用于道具、车辆与硬表面资产；有机对象采用对应的雕刻和拓扑流程。

## 自动安装（推荐）

在 Codex 中复制并发送：

```text
使用 $skill-installer 安装这个技能：
https://github.com/FoolishDeveloper5360/agent-skill-workbench/tree/main/reference-modeling-quality
```

安装器会下载完整技能，无需手动选择路径。安装完成后，在下一轮对话中使用；若技能未出现，再重启 Codex。

## 使用方法

开始执行建模前，Agent 会先说明参考图要求、当前素材能支持的还原范围和需要推断的部分。**只有一张参考图时，必须先提供其他视图的推断图供你确认，收到明确确认后才开始建模。**

直接附上参考图并发送，不需要先整理图片目录：

```text
使用 $reference-modeling-quality，按附件参考图制作可编辑的 Blender 模型。
请先检查现有工具是否可用，将工程和检查点保存在当前项目内，完成质量检查后交付。
```

有具体要求时，可以这样补充：

```text
制作一个用于网页展示的静态道具，总高度 0.4 米，其他尺寸按参考比例推断。
不需要绑定或动画。交付可编辑 .blend、GLB、关键视角对照图和简洁检查记录。
```

以上为调用示例。将尺寸和用途替换为自己的需求，也可以直接给出已有图片的路径。

## 会得到什么

- 可编辑的 Blender 源工程，以及需要的纹理等依赖。
- 按任务要求导出的模型文件；交付 GLB 时，独立回读检查实际导出结果。
- 关键视角对照图、检查结果与已知偏差说明。
- 对应版本的保存目录与文件校验清单。

环境检查、文件保存和校验由 Agent 执行。成果保存在已授权的项目目录内，无需额外云盘；本地保存不等于异地备份。

## 使用前需要做什么

通常只需安装技能、提供参考素材，并让 Agent 使用一个可以保留成果的项目目录。环境检查与路径处理由 Agent 完成。

### 你需要提供的内容

1. **参考素材**：直接上传图片或提供可读取的文件路径；修改已有模型时提供源工程及所需依赖。不要求先整理图片目录，也不强制提供完整多视图；只有一张时，先确认 Agent 提供的其他视图推断图，再进入建模。
2. **保存位置**：可直接说“保存在当前项目内”。已有授权且适合保留成果的项目目录会直接复用；只有没有可用位置时才需要补充路径，无需配置云盘。
3. **影响结果的要求（有则提供）**：用途、真实尺寸及单位、安装点与公差、输出格式、是否需要绑定或动画、面数或纹理预算。没有精确尺寸时可按参考比例建模，但不能据此保证真实尺度；Agent 仅询问会实质影响结果的缺项。

### 参考图要求与单图确认

- **基本要求**：图片可读取，主体轮廓和主要结构清楚可辨。没有固定分辨率要求；严重模糊、遮挡或裁切会影响还原，Agent 必须如实说明具体影响。
- **推荐视角**：正面、侧面、背面或斜视图；关键连接、孔洞和复杂零件可补近景。不强制你提供完整多视图。
- **多图一致性**：尽量提供同一对象、同一版本和同一状态的图片；有差异时说明以哪张为准。存在影响建模的冲突时，Agent 会先指出并澄清。
- **真实尺寸**：需要准确尺度时，提供尺寸及单位或可靠的尺度参照；安装点、公差和插槽尺寸应单独注明。仅凭图片通常不能确定真实大小。
- **如实说明局限**：背面、内部和被遮挡的结构不能凭空当作已知事实。Agent 会区分实际观察、用户指定和推断，不承诺没有证据支持的精确还原。

只有一张参考图时，执行顺序是：

1. Agent 先检查工具与保存位置，读取素材，明确用途及已有尺寸要求，分析可见结构并说明缺失视角与不确定部分。
2. 提供补充视图的二维推断图或示意图，例如缺失的侧面、背面，必要时补顶面；标明“推断方案，非真实参考”，说明关键结构假设。
3. 你确认具体方案；需要修改时先调整推断图，再次确认。泛泛的“开始做”或未回复不算对尚未展示方案的确认。
4. 收到明确确认后，Agent 才开始三维建模，包括粗模。确认表示接受该设计方案，不证明推断结构与真实对象一致。

推断图展示前由 Agent 检查视图之间的结构、比例及尺寸约束是否一致。重复截图、同角度裁切或 Agent 生成的图片不算补充真实视角，不能用来绕过单图确认；单张多视图拼图会按实际覆盖情况分析，不凭空添加缺失视角。

确认针对具体方案版本。明确展示唯一方案后，你回复“按这个做”即可，无需填写表格；有多个方案时需选定，要求修改时会先更新再确认。Agent 会保存方案和确认记录，恢复任务时复用有效记录。粗模先对照原图与已确认方案，通过主要形体检查后再细化。后续新素材或要求导致结构实质变化时，先更新方案并再次确认；按原方案修正网格不重复询问。

如果当前环境无法制作或展示推断图，Agent 必须说明缺少的能力，请你补充参考视图或提供必要工具，不能跳过确认直接建模。

### Agent 开始建模前自动检查

| 检查项 | 需要具备的条件 |
| --- | --- |
| 技能文件 | 能读取本技能的执行规则、参考文档和清单脚本。 |
| 参考读取 | 能实际查看参考图内容；修改已有工程时能读取源文件与依赖。 |
| Blender 操作 | 已有可用的 Blender，且能通过本地脚本或已配置工具实际操作它、保存和重新打开 `.blend`。仅安装 Blender 或仅有聊天窗口不代表已具备操作能力。 |
| 视觉检查 | 能生成并查看模型的检查图，与参考视角对照。 |
| 工程保存 | 已授权的保存目录可以写入和读回，适合保留工程及版本检查点。 |
| 清单校验 | 有可调用的 Python 3.8 或更新版本；附带脚本仅使用标准库，不需要额外 Python 包。 |

技能本身不安装 Blender，也不包含 Blender 连接器。已有可用的脚本操作途径时，无需另装连接器；缺少能力时，Agent 会一次说明具体缺项与最小必要配置，不擅自安装软件。

### 按任务才需要的条件

- **交付 GLB**：需要可用的 GLB 导出与独立回读途径；可以在干净的 Blender 场景回读，不强制安装额外查看器。
- **使用外部纹理或资产**：需要能读取实际依赖文件；云端占位文件应先完整下载。清单脚本不接受符号链接或 Windows 重解析点，Agent 应在普通本地目录准备检查点。
- **绑定或动画交付**：需要相应的制作、导出与变形检查能力；静态模型不要求这些条件。

重开工程、GLB 回读、清单生成和校验是在制作过程中由 Agent 执行的检查，不需要你提前手动完成。其他 Agent 与操作系统的完整建模流程尚未逐一验证。
